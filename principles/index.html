Reference note

Principles

A quiet note on review, early use and fair handling of later value.

Current version: 14 May 2026. This version replaces any previous version.

Purpose

This page outlines general principles for the review, early use and possible later use of conceptual contributions shared by Robert Brogsitter.

It is not meant to make early review, conversation or pilot use more difficult. It is intended to make transparent how fair handling may be approached if substantial value emerges later.

Where no separate arrangement exists

These principles serve as a quiet reference where no separate arrangement has been agreed, documented or is actively being developed.

If a separate written arrangement exists, that arrangement takes precedence. Where no such arrangement exists, these principles provide a general orientation for review, early use, briefing, implementation and possible later fair handling.

Early review and pilot use

A recipient should be able to review a contribution without upfront friction. A first conversation, internal review or limited pilot should not create an immediate financial burden merely because an idea or structured contribution is being considered.

The preferred starting point is simple: no barrier to review, no burden during early use.

Later value

If a contribution later becomes the basis for visible implementation, branding, design, packaging, communication, operational use, third-party briefing or scaling, the underlying conceptual work should be handled fairly.

Such fair handling is not intended to apply to every small test or internal assessment. It becomes relevant where meaningful value emerges beyond the previous status quo.

Commercial sustainability

Any later arrangement should remain proportionate, commercially sustainable and compatible with the recipient’s liquidity planning. It should not create an unreasonable cost burden, restrict ordinary business conduct beyond what is necessary, or become a serious operational threat.

The intended approach is not to block use, but to keep later value-based handling fair, workable and stable for both sides.

Third-party briefing

If a contribution is used as a basis for designers, agencies, implementation partners, communication work, spatial design or technical execution, such use should remain connected to the original review purpose and should be handled with appropriate confidentiality and care.

In short

  • No barrier to review.
  • No burden during early use.
  • Fair handling only if substantial value emerges.
  • Any later arrangement should remain proportionate, sustainable and liquidity-conscious.
