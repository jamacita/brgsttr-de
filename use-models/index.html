Reference models

Use Models

Reference models for later use, implementation and value-based arrangements.

Current version: 14 May 2026. This version is preliminary and may be refined.

Purpose

This page outlines a preliminary model set for situations in which a conceptual contribution moves beyond review or early pilot use and becomes relevant for implementation, briefing, wider use or scaling.

The intention is not to create an upfront burden. The models provide orientation for later stages, where substantial value may emerge beyond the previous status quo.

Relationship to the principles note

The general collaboration principles remain the first reference point for early review and low-friction pilot use. These use models become relevant only at a later stage, when the contribution is considered for visible implementation, third-party briefing or broader use.

See also Principles.

1. Review

A recipient may review a contribution, discuss its relevance and assess whether it could be useful. Mere review should not create an immediate financial burden.

2. Pilot use

Limited pilot use may be appropriate where selected elements can be tested in an existing operational context without creating material cost or legal friction. Pilot use should remain narrow, practical and reversible.

3. Briefing use

A contribution may later be used as a basis for design, branding, packaging, communication, spatial planning, social media, technical execution or other implementation work.

If third parties are involved, such as designers, agencies, implementation partners or communication providers, use should remain connected to the original purpose and should be handled with appropriate confidentiality, care and attribution of the underlying conceptual source.

4. Visible implementation

If substantial elements of a contribution become visible in public-facing use, the underlying conceptual work should be recognised as part of the value creation process.

Examples may include naming layers, visual direction, figures, wording, packaging, signage, service rituals, spatial cues, communication systems or operational concepts.

5. Value-based arrangement

A value-based arrangement should only become relevant where meaningful value emerges beyond the previous status quo. It should not be triggered by every small test, conversation or internal assessment.

Any later arrangement should remain proportionate, commercially sustainable and compatible with the recipient’s liquidity planning. It should not create a relevant cost shock or unreasonable operational burden.

6. Scaling

A separate arrangement may be appropriate if the contribution is used beyond the initial context, for example in a second location, pop-up, rollout, licence structure, franchise model, delivery-kitchen model, investor deck, landlord presentation, brand manual or agency roll-out.

7. Buy-out option

Where a recipient later wants broader freedom to use selected contribution elements without an ongoing arrangement, a clean buy-out model may be considered. Such a model should be clear, proportionate and based on the actual use, development stage and value relevance of the contribution.

In short

  • Review remains low-friction.
  • Pilot use should be narrow, practical and reversible.
  • Briefing use should remain purpose-bound and careful.
  • Visible implementation can make fair handling relevant.
  • Value-based arrangements should be proportionate, sustainable and liquidity-conscious.
  • Scaling or broader use may require a separate model.
