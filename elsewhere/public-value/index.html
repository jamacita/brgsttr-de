Public value · positive sparks · thematic orientation

public value.

Notably well-executed elements in public communication — grouped by field rather than presented as a visible catalogue of individual programmes.

This page is not a ranking, not a programme review and not a comprehensive broadcaster overview. It collects observable strengths: moments of orientation, journalistic care, democratic conversation, cultural breadth, knowledge transfer, public mobility visibility or more accessible public communication.

framing.

  1. No full-format praise: the note identifies a notably well-executed element, not the format as a whole.
  2. No programme link list: the page names formats only inside grouped detail layers.
  3. No completeness claim: the selection is curated, open and extendable.
  4. Public-value focus: relevance lies in orientation, context, participation, access or public judgement.
